# 常见问题

## 必须完成所有题目吗？

不需要。请根据自己的基础和兴趣选择题目。认真完成一部分题目并清楚说明思路，通常优于完成很多题目但没有分析过程。

## 可以使用大模型辅助完成题目吗？

可以。可以使用大模型帮助理解报错、查阅概念和解释代码，但应核对生成内容是否正确。提交时需要能够解释代码的主要流程、输入输出和自己的修改。

## 没有独立显卡怎么办？

基础题和 API 应用题不需要独立显卡。RAG 题目可以使用云端 API 生成回答，并在 CPU 上建立小规模本地向量索引。进阶训练任务可选，不要求所有人完成。

## RAG 程序必须使用 LangChain 吗？

不必须。可以使用 LangChain，也可以自行组合文本切分、Embedding、向量检索和 API 调用。无论采用哪种方式，程序都必须展示检索到的资料来源。

## 什么情况算作“资料中未提及”？

当检索到的文本无法直接支持回答时，应输出“资料中未提及”或类似表述。不能因为模型知道相关常识，就把资料库外的信息当作资料库中的结论。
