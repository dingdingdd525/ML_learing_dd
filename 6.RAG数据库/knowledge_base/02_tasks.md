# 招新题任务说明

## 基础题

基础题包括 Python 环境配置、机器学习基础概念和一个简单的深度学习实践。完成基础题的同学应提交代码、运行结果截图，以及对关键问题的简要解释。

## 应用题：大模型 API 与 RAG

应用题分为两个阶段。

第一阶段要求使用 Python 调用云端大模型 API，完成文本总结、信息提取或问答等任务。API Key 必须通过环境变量或 `.env` 文件读取，不能直接写入代码，也不能上传到公开仓库。

第二阶段要求构建一个最小的 RAG 问答程序。程序需要读取本地资料，将资料切分为文本块，使用 Embedding 模型建立向量索引，并在回答问题前检索相关文本。最终回答中应展示本次使用的资料文件名。

RAG 程序面对资料库中没有答案的问题时，应明确说明“资料中未提及”，不能根据模型自身知识编造答案。

## 进阶题

进阶题包括论文阅读、开源模型复现或训练实验。完成进阶题不是所有报名者的必要条件。没有显卡的同学不需要为了完成进阶题购买硬件，可以使用云平台提供的免费额度，或只完成基础题和应用题。

## 推荐完成顺序

建议零基础同学依次完成基础题、API 调用和 RAG 应用题。有 Transformer 基础的同学可以进一步阅读 LLaMA 论文，并尝试复现 MiniMind 项目的推理或训练流程。
