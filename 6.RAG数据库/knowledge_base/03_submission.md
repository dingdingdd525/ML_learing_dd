# 提交规范

## 提交内容

每位同学应将不同题目的材料整理在同一个项目目录中。项目至少应包含源代码、依赖说明、运行说明和结果记录。

Python 项目建议提供 `requirements.txt`。README 中应说明 Python 版本、依赖安装命令、环境变量配置方式和程序运行命令。

RAG 题目还应保留知识库文件，并提交至少三组测试记录。每组记录应包括用户问题、检索到的文本片段、最终回答和引用的资料文件名。

## API Key 安全要求

真实 API Key、密码和其他敏感信息不得提交到 GitHub，也不得出现在截图中。使用 `.env` 文件保存本地密钥，并在 `.gitignore` 中忽略 `.env`。可以提交 `.env.example`，其中只保留变量名，例如 `LLM_API_KEY=`。

如果发现提交仓库中包含真实 API Key，应立即在对应平台撤销该 Key，并在提交前删除相关记录。
