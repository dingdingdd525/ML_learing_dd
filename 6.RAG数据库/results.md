## 问题：API Key 应如何保存，哪些内容不能提交到 GitHub？

时间：2026-10-09 16:00:41

### 检索结果（Top-3）

**[1] 来源：03_submission.md | # 提交规范 > ## API Key 安全要求  相似度：0.8812**

> # 提交规范 > ## API Key 安全要求
真实 API Key、密码和其他敏感信息不得提交到 GitHub，也不得出现在截图中。使用 `.env` 文件保存本地密钥，并在 `.gitignore` 中忽略 `.env`。可以提交 `.env.example`，其中只保留变量名，例如 `LLM_API_KEY=`。

如果发现提交仓库中包含真实 API Key，应立即在对应平台撤销该 Key，并在提交前删除相关记录。

**[2] 来源：04_faq.md | # 常见问题 > ## 什么情况算作“资料中未提及”？  相似度：0.7918**

> # 常见问题 > ## 什么情况算作“资料中未提及”？
当检索到的文本无法直接支持回答时，应输出“资料中未提及”或类似表述。不能因为模型知道相关常识，就把资料库外的信息当作资料库中的结论。

**[3] 来源：02_tasks.md | # 招新题任务说明 > ## 应用题：大模型 API 与 RAG  相似度：0.7875**

> # 招新题任务说明 > ## 应用题：大模型 API 与 RAG
应用题分为两个阶段。

第一阶段要求使用 Python 调用云端大模型 API，完成文本总结、信息提取或问答等任务。API Key 必须通过环境变量或 `.env` 文件读取，不能直接写入代码，也不能上传到公开仓库。

第二阶段要求构建一个最小的 RAG 问答程序。程序需要读取本地资料，将资料切分为文本块，使用 Embedding 模型建立向量索引，并在回答问题前检索相关文本。最终回答中应展示本次使用的资料文件名。

RAG 程序面对资料库中没有答案的问题时，应明确说明“资料中未提及”，不能根据模型自身知识编造答案。

### 最终回答

回答：API Key 应使用 `.env` 文件保存本地密钥，并在 `.gitignore` 中忽略 `.env`；API Key 必须通过环境变量或 `.env` 文件读取，不能直接写入代码。可以提交 `.env.example`，其中只保留变量名，例如 `LLM_API_KEY=`。不能提交到 GitHub 的内容包括：真实 API Key、密码和其他敏感信息，也不得出现在截图中；API Key 不能直接写入代码，也不能上传到公开仓库。如果发现提交仓库中包含真实 API Key，应立即在对应平台撤销该 Key，并在提交前删除相关记录。

> # 常见问题 > ## 没有独立显卡怎么办？
基础题和 API 应用题不需要独立显卡。RAG 题目可以使用云端 API 生成回答，并在 CPU 上建立小规模本地向量索引。进阶训练任务可选，不要求所有人完成。

> # 招新题任务说明 > ## 进阶题
进阶题包括论文阅读、开源模型复现或训练实验。完成进阶题不是所有报名者的必要条件。没有显卡的同学不需要为了完成进阶题购买硬件，可以使用云平台提供的免费额度，或只完成基础题和应用题。
