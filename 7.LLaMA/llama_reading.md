## 学习笔记：

1，归一化分为前置归一化与输出归一化（前者的方向传播的梯度不容易受到太大的影响，总有一个+1），然后，也可以选择不减去均值（因为后续的偏置可以做到调控不偏差太大）

2，激活函数（我学习的总结）：  
tanh，sigmoid，RELU，Swish（SILU），GELU（这个是正态分布的那个分布函数），门控的有：GLU（是使用sigmoid作为门控），REGLU（使用RELU门控），GEGLU，SwiGLU

3，位置编码，采用旋转矩阵乘k与q，由旋转矩阵的性质，可以得到的是，最终q的转置乘k，得到的值，只是与q，k对应token的绝对位置之差有关。这样，无论我爱猫出现在前面还是后面，爱与猫的绝对位置之差都是1，不会因为位置不同就改变对应的搜索量。（ROPE）

4，adam优化器，使用的是一阶动量与二阶动量来平滑梯度。还有初始的修复（使得除以一个1-贝塔的t次方，确保初始为1），warmup是，初始学习率的慢慢调高，有线性增加的类型。

5，adam对L2正则化的问题。包括不限于：正则化的参数对各个权重影响不同，正则化参数参与动量运算，影响。包括在一些死区（本来不需要更新权重的），但还是以固定学习率的速度更新。

6，flashAttention：不再储存注意力矩阵，而是，分块运算，算完就丢弃。activation checkpointing，梯度检查点，前向传播不再把中间激活全部保留到显存，而是保留激活点。

## 问题回答：

### 1. LLaMA 和原始 Transformer 的关系是什么？

> LLaMA 使用的是哪一类 Transformer 架构？它的训练目标是什么？为什么“预测下一个 token”可以成为生成文本、回答问题等能力的基础？

回答：

LLaMA是使用了Transformer结构下，在LLM领域下的一种扩展。  
使用的是Decoder-only架构。  
目标是预测下一个token。  
因为“预测下一个 token”可以确保给定问题去逐一生成文本，一个个文本到整个句子整段话，从而实现我们的要求。而预测下一个token是一个统一、可训练的问题，方便训练。而从训练效果的角度来说，“预测下一个 token”需要模型隐式学习各种语法语义，事实知识等等。

### 2. LLaMA 相比你已经学习的 Transformer 做了哪些关键改动？

> 请说明 RMSNorm、SwiGLU、RoPE 分别解决或改善了什么问题。无需推导公式，但需要说明它们在模型中的作用。

回答：

架构上面，对应学习笔记的几点。  
RMSNorm是均方根归一化，不需要减去均值，减少了计算量。（因为能力表现上差距不大，并且数值本身就是在0附近的），同时使用了前置标准化，确保输入x先标准化然后再去过隐藏层。这样对比最后标准化来说，计算梯度的时候（求导后，加的残差的那个x梯度为1），不会受到影响，缓解了梯度消失。而原本后置标准化的话，那个x梯度就会乘上那一堆数，导致容易梯度爆炸或者消失。  
SwiGLU是用SiLU做门控，这样既可以选择通过的内容量，也可以选择通过的内容比例，并且，SILU对比RELU，不会造成神经元的死亡。  
RoPE是旋转位置编码，对比原本的Transformer的绝对位置编码来说，RoPE计算相似度的时候，只与2个位置的相对位置有关，更符合语义，尤其对于长文本。

### 3. 为什么 LLaMA 不只是“参数更多的 Transformer”？

> 论文如何处理训练数据来源、数据配比、训练 token 数与模型参数量之间的关系？为什么足够多且高质量的数据对小一些的模型也很重要？

回答：

LLaMA修改了架构，并且不只是堆积参数，而是力求在小模型，低成本下，用更多的数据训练出更好的模型。LLaMA 仅使用公开数据集。配比为：CommonCrawl (67%)、C4 (15%)、GitHub (4.5%)、Wikipedia (4.5%)、Books (4.5%)、ArXiv (2.5%)、StackExchange (2.0%)。（反正就是各方面都涉及一点，确保模型可以理解更多东西。）并且，LLaMA提高了训练token量，确保小模型参量训练更多的数据。  
小模型学习能力有限，更需要高质量数据来去记忆更多的知识。

### 4. 论文中的 zero-shot / few-shot 评测是怎样完成的？

回答：

选择论文中的一个评测任务说明：模型如何把一个分类、问答或推理任务转化为文本生成任务？这个过程是否更新了模型参数？它和微调有什么本质区别？

zoro的是，不给例题直接写，few的是给一部分例题然后去回答同类题。  
把任务写为一段话，然后让模型输出，比如1+1=2吗？只可以说是否，然后模型输出是，通过提示词。没有更新参数，本质区别在于模型参数不变，一个是提示词输入里面涉及到知识，模型本身没有学习到。一个是模型内置知道了知识。

### 5. 预训练模型为什么不能直接等同于聊天助手？

回答：

结合论文中的 instruction fine-tuning 内容，说明 Base Model 与 Instruct Model 的区别。指令微调改变了模型的哪些部分，又没有改变哪些部分？

预训练模型只是针对的是，根据前文，生成下一个最合理的词语。比如说，请帮我写一篇作文，关于大自然。然后模型接着写，不少于800字。  
指令微调是用一系列高质量问答，来让模型学会回答问题。这其中，模型的知识没有改变，但是模型对于知识的利用方式变了，可以去运用知识回答。

└─────────────────────────────────────────────────────────────┘
 
  [Transformer 架构] 
          │ (Decoder-only，因果注意力)
          ▼
  [自回归预训练]
