# 实验报告：从线性模型到神经网络——非线性回归

## 1. 实验目的

通过同一个非线性回归任务（Friedman#1），对比**线性模型**与**全连接神经网络（MLP）**的预测能力，并在此基础上系统探索影响 MLP 训练效果的关键因素（学习率、数据标准化、网络宽度、小批量训练、L2 正则化），理解"模型结构变化如何改变学习能力"以及"同样的结构为何可能学不好"。

## 2. 数据与划分

数据由 `sklearn.datasets.make_friedman1` 生成（该函数包含 sin 项与二次项，本质为非线性回归）：

```python
X, y = make_friedman1(n_samples=1500, n_features=10, noise=1.0, random_state=42)
```

- 样本数：1500；特征维度：10；目标 y 为连续值（量级约 0~30）；噪声标准差：1.0。
- 划分：训练 60%（900）/ 验证 20%（300）/ 测试 20%（300），两次 `train_test_split` 均固定 `random_state=42`，**所有实验共用同一份划分**，保证可比。
- 验证集仅用于每步评估与早停判断，**不参与训练**；测试集仅在训练结束后评估，不参与训练与早停。

## 3. 通用训练设置（所有实验一致）

- 优化器：Adam；损失：MSELoss。
- 训练步数上限 10000；每训练一步都在验证集上评估一次（只做前向）。
- 早停：`patience=1000`，验证损失连续 1000 步未创新低即停止；保存并恢复验证集最优权重。
- 每种配置独立训练 5 次（仅模型初始化种子不同：42~46），报告均值 ± 标准差。
- 评价指标：测试集 MSE 与 R²（R²=1−SS_res/SS_tot）。

## 4. 任务 2.1：线性模型

### 4.1 模型结构

```
nn.Linear(10, 1)，无激活函数
参数量：11（权重 10×1 + 偏置 1）
```

本质是线性回归：ŷ = Wx + b。任务 2.1 单独跑了一次；下表的数值取自任务 2.2 中**相同配置**线性模型的 5 次重复（数据划分与超参数完全一致）。

### 4.2 结果

| 指标 | 数值（5 次均值 ± 标准差） |
|---|---|
| 测试 MSE | 6.0551 ± 0.0003 |
| 测试 R² | 0.7347 ± 0.0000 |
| 最优验证 MSE | 6.2760 ± 0.0001 |
| 训练停止步数 | 6420.8 ± 78.5 |

5 次结果几乎完全一致（方差极小），说明线性模型训练稳定。R²≈0.73 意味着模型只能解释目标约 73% 的方差——**因为数据本质非线性，线性模型存在系统性欠拟合**。

## 5. 任务 2.2：全连接神经网络（MLP）基线

### 5.1 模型结构

```
Linear(10, 24) → ReLU → Linear(24, 1)（输出层无激活）
参数量：289（约为线性的 26 倍）
```

训练方式与 2.1 完全一致：Adam(lr=0.01)、全批量、无标准化、早停 patience=1000。

### 5.2 结果

| 指标 | 线性模型 | MLP（基线） |
|---|---|---|
| 参数量 | 11 | 289 |
| 测试 MSE | 6.0551 ± 0.0003 | 5.7038 ± 0.7442 |
| 测试 R² | 0.7347 ± 0.0000 | 0.7501 ± 0.0326 |
| 最优验证 MSE | 6.2760 ± 0.0001 | 5.8620 ± 0.8005 |
| 训练停止步数 | 6420.8 | 1609.6 ± 148.5 |
| 5 次中 R²>0.80 | 0/5 | 1/5 |

### 5.3 发现的问题

MLP 均值只比线性高 0.015，**5 次中 4 次失败**：失败 run 的最优验证损失 ≈ 6.24~6.28，几乎等于线性模型的最优验证损失（6.276），测试 R² 也贴着线性（0.733~0.734）；仅 1 次（run 3）真正学到非线性（R²=0.815）。

**关键结论：MLP 不是"没能力"，而是"优化失败"。** 同样 patience=1000 下线性模型能跑 6400 步，而失败 run 在几百步内就已停滞——早停只是确认了停滞，不是截断了下降。失败的 MLP 收敛到了"隐藏层近似线性映射"的解（行为等价于某个线性模型），即网络**退化成了线性**。这与数据中 R²≈线性水平、损失≈线性最优损失完全吻合。

## 6. 优化实验（2.2.1）

针对"4/5 次优化失败"，逐一测试四种改进（**每个实验都统一加 L2 正则** `Adam(weight_decay=1e-4)`，避免过拟合）：

| 实验 | 改动（相对基线） | 其他 |
|---|---|---|
| exp1 | lr：0.01 → **0.001** | 全批量、宽 24、无标准化 |
| exp2 | **特征 + 目标标准化**（仅 fit 训练集） | lr=0.01、全批量、宽 24 |
| exp3 | 隐藏层宽度 24 → **64**（参数量 769） | lr=0.01、全批量 |
| exp4 | **小批量** batch=64 + shuffle | lr=0.01、宽 24 |
| exp5 | **组合**：lr=0.001 + 标准化 | 宽 24（排除宽 64 与小批量） |

### 6.1 结果总表（5 次均值 ± 标准差）

| 实验 | 测试 R² | 测试 MSE | 5 次 R²>0.80 | 相对基线提升 | 判定 |
|---|---|---|---|---|---|
| 基线（task2_2） | 0.7501 ± 0.0326 | 5.7038 ± 0.7442 | 1/5 | — | — |
| exp1 lr=0.001 | **0.9385 ± 0.0031** | **1.4041 ± 0.0699** | 5/5 | +0.188 | 明显提高 |
| exp2 标准化 | 0.9278 ± 0.0098 | 1.6481 ± 0.2239 | 5/5 | +0.178 | 明显提高 |
| exp3 宽 64 | 0.9031 ± 0.0396 | 2.2121 ± 0.9046 | 5/5 | +0.153 | 提高但方差大 |
| exp4 小批量 | 0.7520 ± 0.0310 | 5.6585 ± 0.7069 | 1/5 | +0.002 | 无明显提高 |
| exp5 组合 | 0.9181 ± 0.0098 | 1.8686 ± 0.2244 | 5/5 | +0.168 | 低于两个单方法 |

（注：exp2/exp5 的 best_val 为标准化尺度，与其余实验不直接可比；所有实验的 test_mse/test_r2 均为原始尺度。）

### 6.2 单方法分析

1. **exp1（lr=0.001）：最大的功臣**。R² 0.9385±0.0031，5 次全部成功且方差极小。证明基线失败的根源是**优化**（lr=0.01 下梯度震荡/落入坏吸引子），而非模型能力。代价是收敛慢：平均 9118 步（接近跑满）。
2. **exp2（标准化）：非常有效**。R² 0.9278±0.0098，且收敛最快（平均 1781 步）。原因：目标 y 量级大（0~30）而网络初始输出量级小，初始梯度剧烈；标准化后损失面温和，lr=0.01 也不再震荡。
3. **exp3（宽 64）：有效但不稳定**。R² 0.9031±0.0396，5 次都 >0.83，但最差 run 仅 0.8339。增大容量缓解了但未根治优化问题，且参数量涨到 769。
4. **exp4（小批量）：无效**。R² 0.7520±0.0310，仍只有 1/5 成功，模式与基线几乎一样。说明瓶颈不是"全批量的确定性"；batch=64 的梯度噪声不足以逃出坏盆地，且 Adam 的归一化进一步削弱了噪声作用。

### 6.3 组合实验与交互效应

exp5（lr=0.001 + 标准化）结果 0.9181±0.0098：比基线大幅提升（+0.168），但**反而低于两个单方法**（比 exp1 低 0.0203，比 exp2 低 0.0097），未达到"稳定 0.94"的预期。

原因：**超参数之间存在交互，效果不能线性叠加**。
- 标准化之后损失面已变得平坦温和，**此时 lr=0.01 就已稳定**（exp2 的 5/5 成功是证据）；
- 在标准化场景下再用 lr=0.001 反而是劣势：exp5 平均训练 3695 步、最优验证损失 0.0778，而 exp2 只用 1781 步就达到 0.0697——收敛更慢、更浅；
- 即"lr 的最优取值依赖是否标准化"，两个方法的有利区间没有重叠增益。

### 6.4 机制总结（为什么基线会失败、lr 为何如此关键）

- 非凸损失曲面存在多个吸引子：**宽而浅的"坏盆地"**（隐藏层≈线性映射，loss≈6.25，对应"退化"）与**窄而深的"好盆地"**（非线性解，loss≈1.5）。
- Adam 的每步移动距离近似归一化为 lr（与梯度大小基本无关），因此 lr 决定轨迹"粗细"：lr=0.01 轨迹粗，从随机初始化直接落入坏盆地并"正常地"收敛；lr=0.001 轨迹细，能滑入好盆地。
- 全批量 + Adam 是确定性的，落进坏盆地后无噪声逃逸（对应 4/5 失败）；小批量实验的噪声幅度不足以翻越盆地壁（对应 exp4 无效）。
- 标准化通过改变损失面尺度，使 lr=0.01 不再剧烈震荡，从另一个角度解决同一问题。

## 7. 结论

1. **线性模型**（R²=0.7347±0.0000）在该非线性任务上系统性欠拟合，且训练稳定、结果确定。
2. **MLP 基线**（0.7501±0.0326）均值仅略高于线性，根因是**优化失败（4/5 落入坏吸引子）而非表达能力不足**——run 3 已证明结构本身能达到 0.815。
3. **优化后的 MLP**（exp1：lr=0.001 + L2）达到 **0.9385±0.0031**，较线性提升约 0.20，验证了"结构能力 + 得当的优化"才能发挥 MLP 的非线性表达能力。
4. 有效手段排序：**降低学习率（主因）> 数据标准化 > 加宽网络**；小批量单独无效；组合两个有效方法反而次可加（交互效应）。
5. 当前最优配置：**MLP(10-24-1) + Adam(lr=0.001, weight_decay=1e-4) + 全批量 + 无标准化**。

## 8. 局限与后续方向

- 仅测试了单一噪声水平（noise=1.0），未研究噪声对两类模型的影响差异；
- 未做 K 折交叉验证，结论基于单次划分；
- 未分离 L2（1e-4）的单独贡献（它极小，预计影响有限）；
- 未测试"宽 64 + lr=0.001"等非叠加组合（可能优于当前最优）；
- 更现代的表格数据方案（GBDT、TabPFN 等）可作为延伸对比。
