在Python中，你可以使用以下函数来判断一个数是否为质数：

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
```

这个函数首先检查输入的数是否小于2，如果是，则返回False。然后，它使用一个for循环从2开始遍历到输入数的平方根，检查该数是否能被当前的因数整除。如果能整除，则该数是质数。最后，函数返回其平方根，如果不是质数则返回True。

你可以使用这个函数来判断一个数是否为质数：

